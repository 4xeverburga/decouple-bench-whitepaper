% Figure 7 — the native agent: Inspect's react(), and when it compacts.
%
% Unlike a CLI profile, react does not run inside the sandbox: the loop is
% the Inspect eval process on the host, it calls the provider itself (no
% bridge), and only its two tools execute in the workspace container.
% Each turn: an optional compaction check, one generate, an overflow
% check, then tool calls — or, with none, the continue prompt.
%
% Compaction is off unless the profile says `CompactionAuto`. Its default
% threshold is 0.9 of the context window Inspect resolves for the model;
% `openai-api` (OpenAICompatibleAPI) has no native compaction, so on the
% bench's profiles it always falls back to a summary by the same model.
%
% Sources: src/agents/react.py (react(model, [bash(), text_editor()],
% compaction=None | CompactionAuto())); tasks-config.yaml
% (react-glm53-flash, react-glm53-flash-auto); inspect_ai 0.3.286:
% agent/_react.py (loop, _handle_overflow, truncation="disabled"),
% agent/_types.py (DEFAULT_CONTINUE_PROMPT), model/_compaction/auto.py
% (threshold=0.9), _compaction.py (_resolve_threshold,
% DEFAULT_CONTEXT_WINDOW=128_000, memory warning at 0.9 x threshold,
% MAX_ITERATIONS=3), model/_providers/providers.py (openai-api ->
% OpenAICompatibleAPI, no compact()); get_model_input_tokens() on
% glm-5.3-flash and deepseek-v4.1-flash: 1,048,576.
