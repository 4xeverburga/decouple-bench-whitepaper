% Figure 6 — what a curious agent can read from inside its workspace.
%
% Two kinds of leak, and they cost different things. One tells the agent
% it is being measured, which is the precondition for sandbagging or for
% behaving well only when watched; the other hands it the answer. A third
% column is what was checked and holds.
%
% Each entry is the command an agent would type and what it gets back.
%
% Sources: src/bench/solves.py materialise (author bench@localhost,
% message "baseline"); settings.py WORKSPACES (= <repo>/out/workspaces);
% env/solve.yaml (project name bench-solve-mamute, default network, bind
% source = BENCH_CHECKOUT); src/agents/registry.py (OPENCODE_API_KEY
% sk-none: the bridge answers from the host); `gh repo view`.
% Reverse DNS of the container name is Docker's embedded resolver on a
% user-defined network; not yet observed from inside a run.
